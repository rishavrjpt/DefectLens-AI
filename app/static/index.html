How Unsupervised Anomaly Detection Works

Traditional computer vision classifiers require thousands of labeled defect examples for each conceivable flaw type (scratches, cracks, contamination, warping). In factory production lines, anomalies are extremely rare and diverse, making exhaustive defect collection virtually impossible.

DefectLens AI uses One-Class Anomaly Detection: it exclusively learns representations of normal, nominal surfaces. When an anomaly occurs, its intermediate patch representations drift away from the normal memory manifold, triggering an elevated anomaly score regardless of whether that specific defect type was ever seen during training.

Image-Level vs. Pixel-Level Detection

Image-Level Detection: Produces a single anomaly score $s^*$ for the entire product by identifying the most anomalous patch distance. Used for fast binary gating: pass vs. reject.

Pixel-Level Localization: Maps individual patch distances back to their spatial locations on the product surface, applies bicubic upsampling and 2D Gaussian smoothing to generate a dense heatmap. This highlights exactly where on the surface the flaw is located, enabling automated root-cause analysis.

About DefectLens AI

An industrial surface anomaly-detection system built for precision manufacturing quality inspection.

Problem Statement & Motivation

Manual optical inspection in manufacturing is labor-intensive, error-prone due to operator fatigue, and unable to scale with high-speed automated production lines. Conversely, supervised deep learning struggles because real factory defect data is scarce, highly unbalanced, and unpredictable.

DefectLens AI addresses this challenge with modern unsupervised representation learning: training solely on readily available defect-free parts to detect known and unknown structural anomalies instantly.

Core Capabilities

  • Zero Defect Training: Requires only normal surface images to establish a baseline.
  • Pixel-Level Localization: Smooth 2D heatmaps pinpoint defect coordinates.
  • Greedy Coreset Subsampling: Retains 99%+ anomaly recall while reducing memory footprint by up to 90%.
  • Leak-Free Validation: Decision threshold calibrated exclusively on validation normal samples.
  • Fast Local Inference: Sub-50ms CPU/MPS latency suitable for edge inspection stations.

End-to-End System Workflow

01

Data Ingestion

MVTec AD category ingestion, structure verification, and deterministic train/val split.

02

Patch Embedding

ResNet-18 mid-level features (layer2, layer3) extracted and pooled with local receptive fields.

03

Coreset Memory

Greedy minimax facility location subsamples a representative memory bank of normal surface patches.

04

Calibration

Statistical threshold calibration using normal validation samples without touching the test split.

05

Inference & UI

Fast k-NN scoring, spatial heatmap generation, and interactive web dashboard.

Limitations & Responsible Use

Educational Prototype: DefectLens AI is developed for academic research and portfolio demonstration. It is not certified for safety-critical aerospace or medical device quality assurance without rigorous industrial qualification.

Domain Shift Sensitivity: Performance depends on consistent camera positioning and lighting conditions. Significant illumination shifts or camera angle variations may register as anomalies.

Recommendation: In production environments, anomaly detection systems should function as human-in-the-loop screening filters rather than autonomous rejection gates.
